# Web Dev I Lab Assignment 3 - Responsive Personal Portfolio

A one-page responsive portfolio website built using HTML5 and CSS3.

## Features
- **Flexbox:** Used for header navigation and hero section layout.
- **CSS Grid:** Used to organize skill and project cards.
- **Responsive Design:** Mobile-first styling with media queries for tablet and desktop.
- **Animations & Hover Effects:** Keyframe color animation on the hero title, section fade-ins, and smooth card/button hover transitions.

## Steps to View Responsive Behavior
1. Open `index.html` in a browser.
2. Open Developer Tools (`F12` or `Ctrl + Shift + I`) and enable Device Toggle (`Ctrl + Shift + M`).
3. Check the layout at the tested breakpoints:
   - **Mobile (`375px`):** Stacked hero section and single-column grids.
   - **Tablet (`768px` / `48rem`):** Horizontal navbar, side-by-side hero, and 3-column skills grid.
   - **Desktop (`1024px+` / `64rem+`):** Expanded container width and larger hero typography.
